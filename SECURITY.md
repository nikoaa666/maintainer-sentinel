# Security Policy

## Supported versions

Maintainer Sentinel is in early development. Security fixes target the latest published version.

## Reporting a vulnerability

Please do not disclose potential vulnerabilities in public issues. Email the maintainer or open a private security advisory if the repository has advisories enabled.

## Data handling

Maintainer Sentinel reads GitHub metadata and writes reports to stdout. It does not send repository data to third-party APIs unless a future optional integration is explicitly enabled by the user.
