# Changelog

All notable changes to Maintainer Sentinel will be documented in this file.

## 0.1.0 - 2026-05-31

- Added the initial TypeScript CLI.
- Added `scan`, `report`, and `action` commands.
- Added read-only GitHub REST API collection for public repository metadata.
- Added issue bucketing for bugs, enhancements, questions, needs-triage, and security-like reports.
- Added PR queue age and review-state signals.
- Added release readiness summary.
- Added GitHub Actions example workflow.
- Added tests, CI, contributing guide, security policy, and issue templates.
